Adds a dedicated tool window that provides a multi-root workspace view for IntelliJ-based IDEs.

为基于 IntelliJ 的 IDE 提供一个专用工具窗口，以支持多根工作区视图。

Features

  • Displays a file tree with support for multiple root directories simultaneously.
  • Fully integrated with the IDE's file system, providing standard context menu actions (New, Copy, Paste, Delete, Refactor, etc.).
  • Ideal for monorepo workflows, offering an intuitive visual separation of sub-projects.

This plugin is designed purely for file browsing and navigation, complementing the standard Project view.

主要功能

  • 同时显示包含多个根目录的文件树。
  • 与 IDE 文件系统完全集成，提供标准的上下文菜单操作（新建、复制、粘贴、删除、重构等）。
  • 非常适合 monorepo 工作流，提供直观的子项目视觉分离。

此插件专用于文件浏览和导航，是对标准项目视图的补充。
